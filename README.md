# Premium Developer Portfolio Website

Welcome to my personal developer portfolio! This repository hosts a premium, responsive, and highly interactive static portfolio website built to showcase software engineering skills, data science/ML projects, and academic achievements.

## 🚀 Live Demo

Check out the live website: **[danish-arshad.vercel.app](https://danish-arshad.vercel.app)**

---

## ✨ Features

- **Refined Aesthetics**: Editorial, high-end design using custom glassmorphism components, harmonic HSL palettes, and fluid scrolling animations.
- **Light & Dark Theme Toggle**: Adapts seamlessly to system preferences with manual toggle override stored in `localStorage`.
- **Interactive Technical Arsenal Grid**: Showcases skill levels with animated indicator fills based on viewport entry.
- **Dynamic Projects Showcase**: Features custom filter buttons allowing visitors to filter by Web, JavaScript, or Python.
- **Sleek Project Thumbnails**: Replaced standard gradients with high-fidelity project preview assets.
- **Fully Functional Contact Form**: Built with an AJAX backend integration using **FormSubmit** for silent background email delivery to my inbox, complemented by custom green/red success and error glassmorphic toast notification cards.
- **Responsive Layout**: Designed from the ground up to support mobile, tablet, and desktop views with collapse-on-tap navigation menus.
- **High Performance & Accessibility**: Fast loading speed driven by optimized Inline SVG icons (never blurry on high-dpi displays) and clean Vanilla CSS without framework bloat.

---

## 🛠️ Built With

- **HTML5** - Semantic layout structure.
- **Vanilla CSS3** - Custom styling rules, glassmorphism filters, theme variables, and keyframe animations.
- **JavaScript (ES6+)** - Intersecting observer triggers, particle background canvas, filtering filters, custom cursor trail, and form submission APIs.

## 💻 Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/danixh-95/portfolio-website.git
   ```
2. **Navigate into the folder**:
   ```bash
   cd portfolio-website
   ```
3. **Run a local server**:
   Since the project relies on native ES6 modules/canvas assets, running it through a local server is recommended. You can use standard VS Code **Live Server** extension, or Python's built-in server:
   ```bash
   python -m http.server 8000
   ```
4. Open your browser and head to `http://localhost:8000`.
